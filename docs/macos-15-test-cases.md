# Framecho macOS 15 手动测试用例

配合 [macOS 15 支持方案](macos-15-support-plan.md) 使用。项目没有 Xcode 测试目标，`scripts/run-checks.sh` 只覆盖不依赖界面的逻辑；下面这些需要在真机或虚拟机上手动执行。

## 1. 如何使用

**标记**

- **系统**：「15」只在 macOS 15 上执行；「15 + 26」两边都执行，macOS 26 上作为回归，确认改造前的行为没有变化。
- **优先级**：P0 不通过不能发布；P1 应在发布前修复；P2 可记录后跟进。

**测试环境**

| 环境 | 用途 |
| --- | --- |
| macOS 15，Apple Silicon（真机，或用 UTM、Tart 等虚拟化） | 主测试环境 |
| macOS 15，Intel 真机 | 至少执行全部 P0，覆盖 x86_64 |
| macOS 26 | 回归 |

虚拟机通常没有摄像头和麦克风，也没有 Apple Intelligence；涉及录音、摄像头的用例（第 6、7、9 节）需要在真机上执行。

**测试前准备**

- 使用一个**新建的 macOS 用户**测试首次使用和权限流程，不要删除自己账户里的 Framecho 数据。
- 测试用录屏：一段带**中文**旁白、一段带**英文**旁白，各约 2 分钟，中间至少有一次 2 秒以上的停顿；另备一段 10 分钟以上的长录屏。
- 在「系统设置 → 键盘 → 听写」中启用中文和英文听写（G-06 需要临时关掉一种）。
- 可选：一个 OpenAI 兼容 API 的地址和密钥，用于 H-02。
- 每条用例的结果填入第 11 节的记录表。

## 2. 安装、启动与更新

**A-01　首次启动不崩溃**（P0，15 + 26）
- 前置：新用户，未安装过 Framecho。
- 步骤：从 DMG 拖入「应用程序」并打开。
- 预期：App 正常启动并显示首次使用引导；没有崩溃或「已损坏」提示。

**A-02　不缺少系统框架**（P0，15）
- 步骤：打开「控制台」App，开始流式传输后筛选 `Framecho`，启动 Framecho。
- 预期：没有 `Library not loaded`、`dyld` 之类的错误（FoundationModels 在 macOS 15 上不存在，必须是弱链接）。

**A-03　Sparkle 能收到更新**（P0，15）
- 前置：appcast 中有一个比已安装版本更新的版本，其 `minimumSystemVersion` 为 15.0。
- 步骤：菜单栏 → 检查更新…
- 预期：提示有新版本，可下载并安装；安装后版本号正确。

## 3. 权限与首次使用引导

**B-01　引导页列出 5 项权限**（P0，15 + 26）
- 步骤：首次启动，进入「允许访问」页。
- 预期：列出屏幕录制、麦克风、摄像头、输入监控、通知 5 项，**不含语音识别**；在屏幕录制权限交给系统设置处理后，页面底部出现「重新打开」提示，内容不被裁切。

**B-02　设置中的语音识别权限**（P0，15）
- 步骤：设置 → 通用 → 权限列表。
- 预期：多出「语音识别」一项，说明为「将旁白转写为字幕，并让提词器跟随你的讲述。」；未授权时点「允许…」弹出系统对话框，对话框说明文字为中文；拒绝后按钮变为「打开系统设置」，点按后打开 隐私与安全性 → 语音识别。

**B-03　26 上不显示语音识别权限**（P1，26）
- 步骤：设置 → 通用 → 权限列表。
- 预期：没有「语音识别」，其余与改造前一致。

## 4. 截图

**C-01　三种截图**（P0，15 + 26）
- 步骤：分别按 ⌥1、⌥2、⌥3 截取全屏、窗口、区域；区域选择时按空格切换到窗口。
- 预期：都能截图，右下角出现预览卡片；截图内容正确，没有只截到桌面墙纸的情况。

**C-02　识别并复制文字**（P1，15 + 26）
- 步骤：⌥5，框选一段中英混排的文字。
- 预期：文字被复制，排版与原文一致。

**C-03　倒计时与置顶**（P1，15 + 26）
- 步骤：⌥6 倒计时截图；⌥7 截取区域并置顶；⌥8 置顶最近的截图。
- 预期：倒计时结束后截图；置顶窗口浮在最上层，可滚动调透明度，可直接标注。

**C-04　自动遮挡**（P1，15 + 26）
- 步骤：在图片编辑器打开一张含邮箱、手机号的截图，使用自动遮挡的「像素化」和「模糊」。
- 预期：敏感内容被遮盖，可撤销。

## 5. 界面外观（Liquid Glass 的退路）

macOS 15 上这些位置应显示毛玻璃材质，macOS 26 上应与改造前一致（Liquid Glass）。每条都在**浅色和深色外观**下各看一次，并分别放在**白色网页**和**深色视频**上方检查。

**D-01　图片编辑器**（P1，15 + 26）
- 检查：画布上方的工具条、左下角缩放百分比、撤销 / 重做按钮、裁剪时的尺寸标签、低分辨率预览提示。
- 预期：背景为半透明材质，文字和图标清晰可读；没有缺失背景、双层边框或错位。

**D-02　置顶截图**（P1，15 + 26）
- 检查：置顶窗口的工具条、透明度指示、颜色选择条、带强调色的按钮。
- 预期：同 D-01。

**D-03　录制选择器与录制控制条**（P1，15 + 26）
- 检查：⌥4 打开的录制选择器（上下两块面板）、录制中的控制条、悬停提示气泡、「捕获自身窗口」提示条。
- 预期：同 D-01；面板原有的细描边只出现一层。

**D-04　预览卡片的折叠标签**（P2，15 + 26）
- 检查：预览卡片收起后屏幕边缘的标签，以及上面的关闭按钮。
- 预期：同 D-01，关闭按钮在浅色外观下可见。

**D-05　资料库工具栏**（P1，15 + 26）
- 检查：资料库窗口顶部的分类标题与数量、搜索框、网格 / 列表切换、排序菜单、「新建」按钮、检查器开关。
- 预期：各项排布正常、不重叠；macOS 15 上不出现 macOS 26 的共享胶囊背景，标题和「新建」按钮没有多余底色。

## 6. 预览卡片拖拽

**E-01　拖到访达**（P0，15 + 26）
- 前置：设置 → 悬浮窗口 → 「拖出后关闭」**关闭**。
- 步骤：截图后，把预览卡片拖到访达的一个文件夹。
- 预期：文件被复制到该文件夹；卡片仍留在屏幕上。

**E-02　拖出后关闭（放下）**（P0，15 + 26）
- 前置：「拖出后关闭」**开启**。
- 步骤：把卡片拖到访达并放下。
- 预期：文件被复制，卡片随即移除。

**E-03　拖出后关闭（取消）**（P0，15 + 26）
- 前置：「拖出后关闭」开启。
- 步骤：开始拖拽后拖回卡片原处松开，或按 Esc 取消。
- 预期：15 和 26 的结果一致，都在拖拽结束后移除卡片（macOS 26 把取消也报告为拖拽结束），不会卡在拖拽状态。

**E-04　拖拽时关闭 Quick Look**（P1，15 + 26）
- 步骤：用卡片的「查看」打开 Quick Look，然后拖拽这张卡片。
- 预期：拖拽开始时 Quick Look 关闭。

**E-05　拖到其他 App**（P1，15 + 26）
- 步骤：把卡片拖进「邮件」新邮件或其他接受文件的 App。
- 预期：作为附件或文件加入。

**E-06　拖拽后其他交互正常**（P2，15 + 26）
- 步骤：拖拽一次后，悬停卡片使用操作按钮；双击卡片；右键选「从图像中拷贝文字」。
- 预期：都正常响应，拖拽没有接管点按和右键。

## 7. 录屏与 Studio

**F-01　录屏**（P0，15 + 26，真机）
- 步骤：⌥4，选择一个窗口，打开麦克风、系统音频和摄像头，录制约 30 秒后停止。
- 预期：录制完成，Studio 打开；画面、声音和摄像头轨道都在。

**F-02　导出与运动模糊**（P0，15 + 26）
- 步骤：在 Studio 中添加一段缩放和一段 3D 运镜，导出 MP4 1080p、60 fps，开启「运动模糊」。
- 预期：导出完成，视频可正常播放；缩放和运镜处有运动模糊（Metal 着色器在 macOS 15 上正常工作）。

**F-03　其他导出**（P1，15 + 26）
- 步骤：分别导出竖屏和方形画幅；导出过程中点「取消导出」。
- 预期：画幅正确；取消后显示「导出已取消。」，没有残留的半成品文件。

## 8. 字幕转写

**G-01　首次转写请求权限**（P0，15，真机）
- 前置：语音识别未授权（「未决定」）。
- 步骤：在 Studio 打开一段带旁白的录屏，点转写。
- 预期：弹出系统的语音识别授权对话框；允许后转写完成，字幕出现。

**G-02　拒绝权限**（P0，15）
- 步骤：在 G-01 的对话框中拒绝，或事先在系统设置中关闭；点转写。
- 预期：显示「在当前版本的 macOS 上转写，需要在“系统设置”→“隐私与安全性”中允许 Framecho 使用语音识别。」；在系统设置中打开后，再点转写可以成功。

**G-03　中文转写完整**（P0，15 + 26）
- 步骤：转写准备好的中文录屏。
- 预期：字幕从第一句开始，到最后一句结束；**停顿之后的内容不丢失、不重复**；字幕与语音同步，播放时逐词高亮跟随。（macOS 15 上识别准确度可能低于 26，只要内容完整、时间同步即算通过，识别错字记入备注。）

**G-04　英文转写的空格与标点**（P0，15）
- 步骤：转写准备好的英文录屏。
- 预期：单词之间有空格，句末标点紧跟前一个单词；任何位置都没有粘连成 `word.Next` 的情况（尤其注意录屏约 55 秒、110 秒处，那里是分块的切点）。

**G-05　长录屏**（P1，15）
- 步骤：转写 10 分钟以上的录屏，记录耗时。
- 预期：完成转写，字幕覆盖到录屏结尾；耗时记入备注（参考：本机测试约为每分钟音频 2 秒）。

**G-06　语言不可用**（P1，15）
- 前置：在「系统设置 → 键盘 → 听写」中移除当前系统语言（以及英文）的听写，使 App 找不到可用的设备端识别语言。
- 步骤：点转写。
- 预期：显示「这台 Mac 暂不支持用你的语言进行设备端语音识别。在“系统设置”→“键盘”中为该语言打开听写，可能会补上所需的支持。」；按提示启用后可以转写。

**G-07　断网也能转写**（P0，15 + 26）
- 步骤：关闭 Wi-Fi 和有线网络后转写。
- 预期：转写成功，证明识别在本机完成，没有使用服务器。

**G-08　按文字剪辑**（P1，15 + 26）
- 步骤：转写后在字幕里删掉几个词。
- 预期：对应的视频片段被剪掉，播放连贯；切点位置合理，必要时可以手动微调。

**G-09　转写中关闭窗口**（P2，15 + 26）
- 步骤：长录屏转写进行中关闭 Studio 窗口。
- 预期：不崩溃；重新打开后可以再次转写。

## 9. 提词器

已知限制：提词器的自动滚动按空格切词，**中文脚本在所有系统上都不会自动滚动**，下面的跟随用例请使用英文脚本。

**I-01　开启时请求权限**（P0，15）
- 前置：语音识别未授权。
- 步骤：⌥4 打开录制选择器，打开提词器开关并写一段英文脚本。
- 预期：打开开关时弹出语音识别授权对话框。

**I-02　沿用上次的开关时请求权限**（P1，15）
- 前置：提词器开关在上次使用时已打开；之后在系统设置中把语音识别重置为未决定，或换一个新用户复现。
- 步骤：退出并重新打开 Framecho，打开录制选择器中的提词器面板。
- 预期：面板出现时弹出授权对话框。

**I-03　录制开始时不弹窗，跟随讲述滚动**（P0，15 + 26，真机）
- 前置：语音识别已授权（15），麦克风已授权。
- 步骤：开启提词器，开始录制，按英文脚本朗读。
- 预期：录制开始时没有任何系统对话框；提词器随朗读向前滚动，读错或跳过个别词也不会卡住，**不会往回跳**。

**I-04　未授权时只显示脚本**（P1，15，真机）
- 前置：语音识别被拒绝。
- 步骤：开启提词器并录制。
- 预期：提词器显示脚本但不自动滚动；录制本身完全正常，录完的视频没有异常。

**I-05　长停顿后继续跟随**（P1，15，真机）
- 步骤：录制中朗读一段，停顿 5 秒以上，再继续朗读。
- 预期：停顿后提词器继续跟随，不需要重新开始录制。

**I-06　暂停录制**（P2，15 + 26，真机）
- 步骤：录制中暂停，期间说话，然后继续录制并朗读。
- 预期：暂停期间提词器不前进；继续后恢复跟随。

## 10. 字幕整理与智能体访问

**H-01　Apple Intelligence 不可用的提示**（P1，15）
- 步骤：设置 → AI → 字幕整理，选择「Apple Intelligence（本机）」。
- 预期：显示「Apple Intelligence 需要 macOS 26 或更高版本，请改用 OpenAI 兼容 API。」；新用户首次打开时默认选中「OpenAI 兼容 API」。

**H-02　OpenAI 兼容 API 整理字幕**（P2，15 + 26）
- 前置：已填写 API 地址和密钥。
- 步骤：转写后在 Studio 中点「用 AI 整理字幕」。
- 预期：给出修改建议，逐条确认后应用。

**H-03　26 上 Apple Intelligence 照常**（P1，26）
- 步骤：在开启了 Apple Intelligence 的 Mac 上，选择「Apple Intelligence（本机）」整理字幕。
- 预期：与改造前一致，可以正常整理。

**J-01　智能体转写**（P1，15）
- 前置：设置 → AI → 智能体访问 已打开，并按页面上的命令把 Framecho 加入 Claude Code；语音识别未授权。
- 步骤：让智能体调用 `transcribe`，再调用 `cut_words`。
- 预期：首次调用时在 Mac 上弹出语音识别授权对话框；允许后转写完成，`cut_words` 能按词剪辑；Studio 中可以撤销。
